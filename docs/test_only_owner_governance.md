# TEST_ONLY 发布治理变更 · 2026-10-13

项目所有者 KihonnyTsang 明确决定：个人开源 TEST_ONLY 演示包的公开发布改用 OWNER_REVIEW → OWNER_APPROVED；第三方独立审核不再是必要条件。所有者可以审核本人拥有权利的内容。不扩展该决定到真实 Agent 执行、科研结论验证或第三方资料授权。

决策依据为所有者本次直接指令：“同意按照你提出的简化方案实施 ECalX 的 TEST_ONLY 所有者审核机制。”这只授权实施和准备，不是最终版本公开批准。原 P2 和隔离五轮修订四文件、历史 PENDING_INDEPENDENT_REVIEW、所有旧审核及 FAILED 记录原地保留；不追认独立审核通过。旧发行文档中的强制独立审核要求仅在 TEST_ONLY 发布事项上被本决策替代，不改变其历史事实。

保留来源/数据许可检查、凭据/隐私扫描、TEST_ONLY 身份、未知科学性能、完整测试、干净环境安装和发布前检查。所有者公开批准不属于独立科学审核；不会把 chemical_pass 模拟值变为科学事实，不会改变历史 FAILED 或 POSTHOC 事实，M5 继续禁用。

仅在所有者确认具体最终版本、SHA256 及公开文件范围后才能在独立 OWNER_APPROVAL.json 中记录 OWNER_APPROVED；review.json 始终保留未签署 OWNER_REVIEW 审核基线。Git 提交、推送、公开发布和部署另须明确执行指令，本轮均未授权执行。
