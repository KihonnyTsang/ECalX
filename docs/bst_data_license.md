# BST参考数据的许可处理

核查日期：2026-10-21。对象是从Dai等论文图8A–D数字化得到的204点数据，不是软件代码许可。

## 核查依据

- [出版方的论文页面](https://ceramics.onlinelibrary.wiley.com/doi/abs/10.1111/ijac.13384)列出DOI、2019年在线发表日期及2020年卷期，版权标记为©2019 The American Ceramic Society。所检查页面未提供可据以确认这份204点数字化数据允许公开再分发的明确许可。
- [Wiley许可说明](https://authors.wiley.com/author-resources/Journal-Authors/licensing/licensing-info-faqs.html)区分订阅文章协议与开放获取的Creative Commons许可；作者自身的再用权不等于软件维护者自动拥有同样的权利。
- [Wiley再用权限入口](https://www.wiley.com/research-intelligence/content-solutions/permissions/general-queries)提供针对具体内容的许可申请方式。能访问论文、附DOI或去掉私人路径，本身都不能证明已获本次分发许可。

## 本次发行决定

目前无法确认这份数字化数据随开源软件公开分发的许可。本候选采取“不附带数据、由用户自备合法参考文件”的方式，不对所有司法辖区的数据权利作统一法律结论。没有申请许可、联系第三方或接受合同。

- 204点原冻结数据及SHA256保持不变，仅留在原本地研究目录。
- 已制作另一个脱敏副本，核对全部记录和来源字段，记录新SHA256；它位于发行候选之外的本地审阅区，不进入GitHub源码目录、源码压缩包或wheel。
- PDF、论文原图、坐标图片、全文摘录、私人数据库、原始实验附件均不打包；测试也不嵌入204点数组。
- 发行的是本项目代码、使用说明、DOI/图号/来源标记及两个版本哈希。MIT仅适用于相应自有软件代码，不宣称覆盖论文及其数字化数据。
- 工具要求用户选择合法取得且哈希匹配的脱敏CSV；缺失、读取失败或版本不匹配都不输出数值。不会自动下载论文、隐含加载作者数据或用示例数值代替计算。

如后续取得明确覆盖本次数据分发方式的许可，可另行审阅数据是否附带；本轮没有为此新增审核流程，也未推送或发布。
