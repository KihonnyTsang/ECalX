# 0.2.0b1 发布前验证（2026-10-14）

实测 macOS ARM64 / Python 3.11；Linux / WSL2 未实测，原生 Windows 不支持。测试全部使用原创合成软件数据，结果不是科研测量、科学模型验收或真实供应商验收。

## 独立安装

两个全新 venv：一套从源码以 `pip install ".[dev]" -c requirements-tested.txt` 安装；另一套只安装构建后的 `ecalx_byo-0.2.0b1-py3-none-any.whl` 及其依赖。不是 editable 安装，不复用开发版的虚拟环境。两套 `pip check` 均无依赖冲突。

requirements-tested.txt 记录本次 47 个运行/测试依赖的实测版本，仅为 macOS/Python 3.11 复现约束。常规第三方安装仍用 `pip install .`；项目声明有范围的公开依赖。第三方许可元数据和实际许可文件哈希见 docs/dependency-licenses.json，未发现缺少许可元数据的包，未重打包第三方库。
