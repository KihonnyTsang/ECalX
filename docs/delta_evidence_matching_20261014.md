# 0.2.0b3 ΔE 匹配规则

ΔE 幅度匹配保留原文报告的组成、温度、direct/indirect、来源、标签口径和符号。缺起终点的记录可以匹配 ΔE；上限、峰值和含义未知标量不代替 ΔE。

显式路径查询只将相同真实端点作为路径匹配；缺端点的同 ΔE 记录作为“幅度匹配、路径未确认”辅助证据。已知且矛盾端点不放宽成缺端点。用户上传的路径不等于独立核验路径。

描述统计按来源/组成/温度/ΔE/方法/物理量口径/符号/协议分组。直接法温降幅值与间接法 Maxwell 估算保持分开，不改变符号、不作跨协议排名。工具保存前 50 个统计组，并给出完整组数。

生成种子保留来源与覆盖说明；新增候选 generated_unverified，种子标签不转为预测。BYO 无模型，正式 ΔT/ΔS unknown、M5 禁用。

[合成 delta_labels CSV](../examples/SYNTHETIC_TEST_DATA_delta_labels.csv) 的 ΔE=20 查询匹配 5 条；仅上限和仅峰值不命中。0→20 路径有 1 条提供端点的匹配和 3 条辅助证据；20→0 严格 0 条、辅助 3 条。已知 10→30 路径不伪装为 0→20。测试直接法 1/3 K 均值为 2 K；间接法 -0.5 K 保持独立。这些是合成软件测试值。

本轮还在隔离环境以合成导入数据验证 ΔE=10/20/30/40/50、12.5/0.125/0.001 的完整检索工具链，详见 [validation.md](validation.md)。不分发个人真实库、标签或模型验证记录。
