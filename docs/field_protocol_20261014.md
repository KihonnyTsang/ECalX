# 0.2.0b2 电场协议边界

研究条件支持常用脉冲、自定义路径或协议未知，默认未知。常用参考为 `0→峰值→保持→0`，标为 ASSUMED；峰值单独填写，不从 ΔE/上限代填，保持时间/升降速率/测量分支未知时为 null。

该参考在 Goals 中投影为升场段，只按实际提供端点匹配，不代表完整脉冲或分支已核实。导入页“假设采用标准脉冲协议”默认关闭，不改原始数据、真实端点或历史任务。

独立峰值 e_peak 换算值保存在 raw_metadata 的 actual_peak_kV_cm；不生成起终点。用户上传 OBSERVED 文字不会自我认证为独立核验协议。BYO 无独立协议覆盖层和预测模型，正式 ΔT/ΔS unknown。

[缺端点测试 CSV](../examples/SYNTHETIC_TEST_DATA_missing_endpoints.csv) 前四行端点为 null；启用假设后仍不写回。第五行有上传端点，其协议仍未经核验。测试通过 Streamlit AppTest 检查确认/返回修改、假设开关及历史不变。这些是合成软件测试，不是实验验证。

在线参考仅投影宿主生成的条件及 ASSUMED 标记，不包含上传协议自由文本/raw_metadata。出站契约用模拟响应测试，尚未独立在线验收。
