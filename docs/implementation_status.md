# ECalX 0.2.0b2 实施状态

基于已验收的BST独立发行候选整理beta.2；本轮只更新版本、CSV格式说明与发行资料，不新增模型或研究功能。

- 既有本地研究：CSV/Excel导入、本地PDF提取、条件核对、证据检索、候选组成及化学校验、报告和连续追问。
- 既有BYO API：用户自己的Key、模型配置与请求/Token控制；真实供应商在线验收仍为NOT_RUN。
- BST：包内原计算代码，用户选择合法参考CSV，冻结校验、三类结果标记、曲线和越界拒绝。无数据不输出ΔT。
- 新增文档资源：43列空白CSV格式模板与逐字段说明；没有放宽数据校验，没有提供204条数值。
- 科学边界：候选性能unknown、M5禁用；BST结果仅为研究性文献插值。

原独立候选182项通过结果保留在本地发行记录中；本轮安装与检查见[validation.md](validation.md)。数据许可处理见[bst_data_license.md](bst_data_license.md)。原科研数据库、模型与历史结果未修改，付费API调用0，未推送或发布。
