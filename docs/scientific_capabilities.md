# v0.2.0-beta.3 科学功能核验

## 实际支持的温变计算

BST 计算继续使用包内既有 `BSTInterpolator`；与开发副本逐字节一致，没有训练、拟合新科研模型或更改冻结 204 点 CSV。参考文件 SHA256 为 `92a17a6e4f10487d747c7e316883fbab88c1cdc03e6efdec0e11d4a18851ec89`，原始含路径版本也须通过原哈希后才允许移除路径元数据。

实际核验：Ba0.8Sr0.2TiO3 / 303 K / 标称撤场幅值 20 kV/cm 得 `1.1502485148514852 K`；323 K / 30 kV/cm 得 `1.539950495049505 K`。沿原曲线做温度插值，相邻参考组成再做组成插值。x=0.05–0.35，仅 10/20/30 kV/cm；各温度范围取支撑曲线交集。Ca、薄膜、氧计量改变及越界条件拒答。

文献口径是撤场后的正温降幅值，未统一完整波形、热损与符号，不能称为当前 0→20 kV/cm 加载过程的实测或严格定量预测。卡片、报告、独立工作台计算都保留该区别。Dai 等：[DOI 10.1111/ijac.13384](https://doi.org/10.1111/ijac.13384)。公开仓库不含 204 点数值集或完整参考曲线截图。

## 已有 RF/XGBoost 接口的实际运行

使用本版 `ecalx_local.exploratory.estimate`，显式指定原个人科研工程，以已有模型/训练集/OOF/适用域工件进行哈希核验后真实推理；网络连接被阻断，未调用 fit 或训练入口，未写入原数据库。测试输入：BaTi0.89Sn0.11O3、343 K、ΔE 10 kV/cm、bulk ceramic、路径 unknown。

| 模型 | direct ΔT (K) | indirect ΔT (K) |
| --- | ---: | ---: |
| RandomForest | 0.19831338228424375 | 0.17217811835904837 |
| XGBoost | 0.3040201663970947 | 0.16601574420928955 |

四种均返回 `RESEARCH_ONLY`，目标是 `source_reported_delta_T_K`。它们是文献标签研究性估计，不是实验验证、独立最终外测或已校准区间，也不能据此作真实性能排名。

模型实际适用域：direct 温度 150–418 K、ΔE 4–150 kV/cm；indirect 温度 209–468 K、ΔE 2–80 kV/cm。除此之外，原名义 ABO3 元素/原子分数边界、组成近邻半径、方法及块体陶瓷限制继续生效；只处于 T/ΔE 边界内不足以准入。四种模型都实际拒绝 900 K、PbTiO3 与明确 0→10 kV/cm 路径，预测值保持 null。

公开 BYO 包未包含该科研工程的 ML 模块、权重、训练集、验证表及其资料权限；包内保留原接口、拒答逻辑和收据卡片适配器。纯 BYO 安装返回 `UNAVAILABLE / no_user_model_provided`，不会自动加载相邻项目。个人模式必须由用户显式配置 `ECALX_MODE=personal`、`ECALX_SCIENCE_ROOT` 和 `ECALX_LOCAL_STORAGE`，并自行具备完整原工件；这不是通用用户模型上传支持。

## M4 与候选排名

沿用 `maxwell-toy-1` 未校准演示方程和冻结候选域。303 K / 0→20 kV/cm 下，10 个生成候选中 5 个 BST 准入、5 个含 Ca 域外；2 个初始反馈加 3 轮固定 RBF GP/EI，共评价 5 个。最高模拟评分 `0.4980345939556777`，对应 Ba0.75Sr0.25TiO3；分值不带 K，不转写为 ΔT。主动学习对已揭示模拟反馈更新 GP 是原流程的一部分，没有重训 RF/XGBoost。

候选卡片以同一最新 run 的实际观测排序；文献参考与研究模型估计不参与混合排名。明确场路径不能通过删除输入、改成 unknown 或借用其他 run/任务收据绕过。历史和正式原结果保持。
