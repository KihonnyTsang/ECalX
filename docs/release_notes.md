# ECalX v0.2.0-beta.3

Python 包版本：`0.2.0b3`。建议发布为 **Pre-release**。

## 本版更新

- 修复已完成研究页面因默认渲染巨量 JSON 及隐藏内容造成的严重卡顿；结果、详情、图表和下载按需生成，历史分页，运行中才轮询。
- 简化研究工作台，支持允许元素及排除元素、自动组成枚举与逐候选独立化学校验。
- 接入既有 M4 虚拟实验、固定 RBF GP/EI 主动学习和同协议模拟排序；域外候选保持待研究。
- 恢复分页候选卡片，分别显示模拟评分、实际可用的 BST 文献插值 ΔT 和符合条件的个人研究模型收据。
- BST 插值保留在研究工作台内部；参考数据可一次导入、复用，计算可随任务保存到历史和报告，曲线按需展开。
- 保留历史研究、Markdown/JSON 报告下载、API 配置和本地数据库构建。
- README 增加七张最终版本浏览器截图、安装说明及 ΔT 来源说明。

## 安装

Python 3.11+，解压本版本源码并进入项目目录：

```sh
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install .
ecalx
```

## 科学与数据边界

- M4 结果是未校准虚拟环境的**模拟评分**，不带 K，不代表实测 ΔT。
- BST 数值是块体陶瓷文献撤场正温降幅值的研究性插值；只在组成、温度及 10/20/30 kV/cm 覆盖内计算，不代表当前加载协议的实验结果。
- 参考 CSV、论文 PDF、原图、私人科研数据库、实验日志、模型权重和 API Key **均不随包分发**。无合法且哈希匹配的数据时不输出 BST ΔT。
- 既有 RF/XGBoost 研究性接口和严格适用域检查保留；公开 BYO 包不包含其私人科研工件，不能开箱预测通用材料 ΔT。模型估计未经过独立最终外测，明确场路径仍拒答。
- 全部生成组成为待验证候选，正式 M5 推荐未启用。本版未新建科研模型、未重训、未调用付费 API、未修改原始科研数据库。
