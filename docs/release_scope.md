# 0.2.0b1 拟公开范围

拟用标签 `v0.2.0-beta.1`；当前仅本地准备，待所有者审阅。

- `ecalx_local/`：Streamlit UI/CSS、条件/协议、任务适配、导入、报告、追问及 BYO 配置/预算/出站投影。显式 personal 接口保留，无作者资产。
- `src/ecalx/`：原自有 MIT 科研代码，包括 Agent/传输/工具契约、数据仓库、单位/条件解析、计量/候选生成/化学检查、服务与实验框架。BYO 不注册实验/模型/训练工具，不创建实验后端。
- `tests/`：临时工作区内的软件回归与模拟 HTTP 契约，假 Key 永不发送。所有测试数据是合成的。
- `examples/`：三个原创 CC0-1.0 CSV 和说明，不包含真实测量、私人数据库或论文。
- 安装元数据、应用入口、主题、MIT LICENSE、README、公开规则/限制/验证说明、依赖版本/许可、源码来源摘要、文件清单与 SHA256。

精确文件范围以 `audit/public_files.txt` 为准；`audit/SHA256SUMS` 覆盖除两个清单本身外的所有公开文件，两清单哈希另由发行目录外的锚点记录，避免自引用。

必须排除：私人 data / config、模型、原工作簿/PDF、来源覆盖层、历史任务/报告、API Key、`.env`、账本/任务数据库、绝对个人路径、虚拟环境、缓存、构建输出和测试/浏览器工件。开发源快照的相对文件名和哈希记录在 `audit/source_provenance.json`，不包含开发机绝对路径。

旧版 OWNER_APPROVAL.json 的范围只有 0.1.0rc3-final1；从本版本文件树移除，原历史仍保留，不视为新批准。来源哈希、审计 PASS 和本地 Git 提交均不代表批准公开。此次未推送、未发布或部署。
